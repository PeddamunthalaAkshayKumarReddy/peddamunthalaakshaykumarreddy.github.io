# P M Akshay Kumar Reddy · Data Analyst Portfolio

A one-page static site: `index.html` plus its images. No build step.

## Put it online for free

**Netlify Drop (fastest, no account needed to try):** open https://app.netlify.com/drop and drag this whole folder onto the page. Netlify gives you a link straight away; create a free account to keep it and rename the address.

**GitHub Pages (best for a portfolio link on your resume):**
1. Create a free GitHub account, then a new public repository named `<your-username>.github.io`.
2. Click *Add file > Upload files*, drag in all the files, and commit.
3. Open *Settings > Pages*, set Source to *Deploy from a branch*, branch `main`, folder `/ (root)`, and save.
4. After a minute the site is live at `https://<your-username>.github.io/`.

## Edit

All text is in `index.html`. To swap a dashboard image, replace the image file with one of the same name (a `-sm` file is the thumbnail).
